Requisitos
Crie uma página web simples que terá diferentes seções para diferentes unidades de medida. O usuário pode inserir um valor para converter, selecionar as unidades a serem convertidas e visualizar o valor convertido.


- [x]  O usuário pode inserir um valor para converter.

- [x]  O usuário pode selecionar as unidades a serem convertidas de e para.

- [x]  O usuário pode visualizar o valor convertido.

- [x]  O usuário pode converter entre diferentes unidades de medida, como comprimento, peso, temperatura, etc. (mais informações abaixo).

Você pode incluir as seguintes unidades de medida para converter entre:

Comprimento: milímetro, centímetro, metro, quilômetro, polegada, pé, jarda, milha.

Peso: miligrama, grama, quilograma, onça, libra.

Temperatura: Celsius, Fahrenheit, Kelvin.
